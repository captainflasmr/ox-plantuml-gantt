An Org Export (=ox=) backend that translates Org headlines into
[[https://plantuml.com/gantt-diagram][PlantUML Gantt]] syntax.

** Installation

Add the package to your load path and require it:

#+begin_src elisp
(add-to-list 'load-path "/path/to/ox-plantuml-gantt/")
(require 'ox-plantuml-gantt)
#+end_src

Dependencies: Emacs 27.1+, Org 9.3+.

** Usage

Open an Org file annotated as described below and press:

- =C-c C-e g p= — export to a PlantUML buffer
- =C-c C-e g f= — export to a =.puml= file on disk

** Rendering

=plantuml-mode= (MELPA) is configured in =init.el= to render charts with
a local PlantUML jar (=~/.emacs.d/plantuml.jar=, jar execution mode, PNG
output). Requires Java on your system.

Open the exported =.puml= file (auto-detected by =plantuml-mode=) and:

- =C-c C-c= (=plantuml-preview-buffer=) — render the chart in a preview buffer
- =C-u C-c C-c= — render in a new window
- =C-c C-u= / =C-c C-d= — resize the preview

The PlantUML jar can be downloaded from
<https://github.com/plantuml/plantuml/releases/latest>; the version in
use must support =lasts=, =starts=/=ends=, and =is N% completed=
(anything ≥ 1.2024 works; if a chart fails to render, update the jar).

Pipe the resulting =.puml= into PlantUML to render the Gantt chart.

** Org File Format Mapping

| Org construct                                | PlantUML Gantt output                          |
| -------------------------------------------- | ---------------------------------------------- |
| Headline with children                       | =-- Title --= section separator                |
| =SCHEDULED:= timestamp                       | task start date                                |
| =DEADLINE:= timestamp                        | task end date                                  |
| =:EFFORT:= (e.g. =2d=, =4h=, =1w=, =12:00=)  | task duration                                  |
| =:BLOCKER:= (title of another task)          | =happens after [Other Task]= dependency        |
| #ERROR                                       | =is N% completed= progress                     |
| =TODO= keyword =DONE=                        | =is 100% completed=                            |
| =TODO= keyword =IN-PROGRESS=                 | =is 50% completed=                             |
| =[N%]= in the headline title                 | stripped from the task title                   |
#+TBLFM: $1=:COMPLETED:= (0-100)

A leaf headline (no children) becomes a task only if it has a
=SCHEDULED=, =DEADLINE=, or =:BLOCKER:=; other headlines are ignored.
When both a date and =:BLOCKER:= are set, the date takes precedence and
the dependency is not rendered. If a task has both a schedule and a
deadline, keep them on the same planning line (as Org itself inserts
them via =C-c C-s= / =C-c C-d=).

Example:

#+begin_src org
,* Phase 1: Core Engine
,** DONE Design Architecture
,   SCHEDULED: <2026-09-01 Tue>
,   :PROPERTIES:
,   :EFFORT:   3d
,   :END:
,
,** IN-PROGRESS Implement Parser Backend
,   :PROPERTIES:
,   :EFFORT:   5d
,   :BLOCKER:  Design Architecture
,   :COMPLETED: 60
,   :END:
,
,** TODO Render Pipeline
,   DEADLINE: <2026-09-20 Sun>
,   :PROPERTIES:
,   :BLOCKER:  Implement Parser Backend
,   :END:
#+end_src

Note: =IN-PROGRESS= must be defined in =org-todo-keywords= (along with
=DONE=) for the keyword-based progress mapping to work, e.g.:

#+begin_src elisp
(setq org-todo-keywords '((sequence "TODO(t)" "IN-PROGRESS(i)" "DONE(d)")))
#+end_src

See =sample.org= for a complete example.

** Customization

| Variable                                   | Default  | Description                                   |
| ------------------------------------------ | -------- | --------------------------------------------- |
| =ox-plantuml-gantt-print-scale=            | =daily=  | =daily=, =weekly=, or =monthly=               |
| =ox-plantuml-gantt-close-weekends=         | =t=      | close Saturdays and Sundays                   |

Both can be overridden per-file with the =GANTT_PRINT_SCALE= and
=GANTT_CLOSE_WEEKENDS= export keywords:

#+begin_src org
#+GANTT_PRINT_SCALE: weekly
#+GANTT_CLOSE_WEEKENDS: nil
#+end_src
